# 14 合并决策与兼容性

## 优先采用的最新决定

- 8ADC持续、主六路+独立AUX-MID，不使用六路内部复用。
- 核心125MS/s，FIR真正125MHz而不是外包装125、内部250；DMA仍200MHz。
- RX HB19→FIR75总D4，TX逆序总L4。RFDC内部ADC D8不变。
- 四组各四同功能bank轮换：可用广播预填，选中捕获，冻结A/B直接读，无bank间复制；“Bank2采集”等为瞬时例子。
- EOP共同选档、默认选中HV记录；仲裁/记录策略与量程资格分开。
- 普通SG软件ring不启用cyclic；DMA/DDR/host完成与RAW完成分开。
- 参考ZU27DR Gen1；Gen3 8GS/s/16倍不是该器件目标，真实板卡仍待确认。

## 对旧包的具体处置

活动旧名称rx_decim8/tx_interp8更名为rx_decim4/tx_interp4，sample_rate_gearbox删除。旧滤波候选和历史test日志在provenance ZIP内，不参与活动测试或代码生成。ABI升5以避免旧解析器接受不同rate/count/source意义的数据。地址孔径保留为提案；寄存器只在已预留区新增，新增bank快照0x3000区。

B口8192深度是128bit端口的正确新值，不得误替换为16384；RFDC D8也是正确新值。62.5MHz仍可能作为滤波阻带边缘，而非核心时钟。机械全文替换这些数字是错误的。

## 不提升为已证实结论

100MHz带宽是本profile数值目标，不是仪器已验收；1536是优化FIR算量不是综合；2400~2900是约定功能范围规划；4bank并不保证任意延迟和停顿；63tap不是已批准Farrow；2nsGSC不是2ns授时精度；质量旁存储尚未实现；Python通过不代表RTL/CDC/板级通过。

未确认完整part/BSP、native映射、增益顺序、阈值、检测上界和实现latency，保留空值和阻塞检查，不为使“包检查通过”填造数据。
