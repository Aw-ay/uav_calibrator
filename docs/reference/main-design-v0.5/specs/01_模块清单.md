# 01 模块清单（v0.5）

所有条目均为DESIGN_ONLY，路径是后续实现目标，不是本包已有可综合RTL。模块字段以contracts/module_catalog.json为准。

| 模块 | 时钟域 | 范围 | 责任及验收边界 |
|---|---|---|---|
| `rfadc_stream_adapter` | clk_rf | BASE | 八路独立ADC的native到canonical适配；每路500MS/s复数；按真实tile/stream映射，不把I/Q或lane误当物理ADC。 验收：单调递增I/Q独立序列逐lane、逐H/V、逐量程无误；不能将word数当复样点数。 |
| `native_overload_monitor` | clk_rf | BASE | 抽取前4lane过载/near-clip聚合，结合RFDC过阈值事件并按时间归属脉冲。 验收：在两次抽取保留样点之间注入一次过载，记录必须保留；未知ADC硬过载不能用DDC幅度无过载替代。 |
| `channel_epoch_aligner` | clk_rf | BASE | 八路序号/时间/MTS检查。共同时钟失效使全组invalid；AUX源切换或单独失效仅标AUX，不能暂停六路测量。 验收：ADC3/7源切换期间ADC0/1/2/4/5/6样点编号连续；共享clock失效正确更新epoch。 |
| `rx_decim4_wrapper` | clk_rf | BASE | 四组HB19 D2 + FIR75 D2，全程clk_rf125MHz，4->2->1复SPC；独立8路I/Q历史，无跨频率gearbox。 验收：所选FIR定点golden、145参考差异、全部八路连续性和OOC资源/时序；不得凭系数响应测试声称硬件通过。 |
| `fixed_round_sat` | clk_rf | BASE | 显式有符号缩放、convergent舍入、饱和与粘滞溢出。 验收：正负边界、tie-to-even、负数符号扩展与模型一致。 |
| `global_sample_time` | clk_rf, clk_ctrl | BASE | 64bit GSC以500MHz刻度记账，clk_rf125MHz每拍加4；四lane为base+[0..3]；epoch/PPS快照和跨域原子读取。 验收：不随DMAready停顿；64bit读不撕裂；PPS精度标记与2ns单位分开。 |
| `pulse_detector` | clk_rf | BASE | 功率域噪声与门控阈值、滞回、EOP保持、最大脉宽、RX状态有效性。 验收：脉冲跨block/跨bank、低SNR、长尾与未检测区不伪造。 |
| `range_qualifier` | clk_rf | BASE | H/V三档在线峰值、能量、过载、档间线性一致性及条件SNR统计。 验收：common前端压缩不可观测时报告疑似/不确定；不读取仿真真值；EOP输出带valid。 |
| `range_selector_eop` | clk_rf | BASE | 在三档最后写入和资格流水完成后按已校准实际增益顺序选整脉冲共同H/V；全无效INVALID；normal只发布所选组，诊断保留策略独立。 验收：后沿过载被计入，绝不无条件降到LOW；一个脉冲不换档。 |
| `pulse_context_latch` | clk_rf | BASE | 冻结pulse_id、bank_generation、窗口、系数版本、时钟epoch与命令版本。 验收：已排队脉冲不被新配置改写；输出descriptor与实际payload一致。 |
| `capture_bank_manager` | clk_rf, clk_mem | BASE | 四组四bank轮换：可用bank广播预填、主三档原子准入、窗口上限保护、FROZEN_PENDING、资格/选档后发布、双消费者引用和epoch/generation归还；不在bank之间复制波形。 验收：固定bank角色禁止；满长count16384可表示；最坏检测延迟历史；不得覆盖冻结记录；迟到/重复ACK无效；复位先quiesce再换epoch。 |
| `capture_bank_ram` | clk_rf, clk_mem | BASE | 四个stream_group各N_BANK独立64bitHV缓存；AUX不占用主MIDbank。 验收：异步端口无同地址写读冲突；环绕与奇数起始样点正确。 |
| `capture_pdw_writer` | clk_rf | BASE | 基础ToA/PW/peak/energy/flags与EOP事件；只称CAPTURE_PDW。 验收：无需等待host精分析；UNKNOWN或invalid字段有标志。 |
| `event_mailbox` | clk_rf, clk_mem, clk_ctrl | BASE | 多个生产域各用CDC FIFO，汇入ctrl域事件队列；快照16个32bit字后显式POP。 验收：IRQ为水位/故障电平；重复读不误POP；溢出计数；不丢高优先级fault。 |
| `frozen_frame_reader` | clk_mem | BASE | 四组独立冻结记录队列串行进入一DMA；主组三档关联，AUX独立capture_id和TXevent关联；公平仲裁与显式丢帧。 验收：记录级仲裁锁到最终握手；奇数起点和环绕；RAM在途读信用；READER_DONE不等BD_DONE；背压不影响已接受回放时间。 |
| `iq_frame_formatter` | clk_mem | BASE | 固定128字节header、payload、可选16字节CRC尾；不是等待最终host PDW。 验收：字节布局可被C/MATLAB共同解码；CRC开关/长度完全一致。 |
| `crc32c_stream` | clk_mem | RECOMMENDED | 可选流式payload CRC32C；结果放尾部，不能在header中假装提前已知。 验收：已知向量、非整拍TKEEP和背压一致；关闭时CRC_UNAVAILABLE标志。 |
| `replay_descriptor_queue` | clk_rf, clk_ctrl | BASE | 固定容量目标命令/脉冲回放队列，保留时间、所需数据和系数版本。 验收：队满明确拒绝；没有host回传依赖；不能改变已接受时刻。 |
| `replay_legality_checker` | clk_rf | BASE | 检查data_ready、guard、计划RX/TX占用、RF状态和存储/读端口资源。拒绝source_role=RF_LOOPBACK/settling/unknown的回放，防止自激。 验收：delay>PRI按时隙而不是一概拒绝；未知雷达时序不承诺未来无冲突。 |
| `replay_reader_scheduler` | clk_rf | BASE | 用GSC绝对时间预取选中档A口数据，统一扣固定实现延迟；欠载中止并记日志。 验收：从冻结A口预取，目标输出时刻反推读时刻；考虑pretrigger位置和latency，too-late拒绝；RAM_READ_DONE/TX_PIPELINE_DONE/RF_DONE独立。 |
| `rx_cal_executor` | clk_rf | FULL_A | 本机接收逆校准；初版复增益/公共整数时延，扩展2x2与因果FIR。 验收：不双补FIR群延迟；不能实时实施无预延迟的负延迟。 |
| `fractional_delay` | clk_rf | FULL_A | 8ns内分数波形延迟；结构/阶数尚待全±50MHz验证，63tap仅资源占位，不能当已批准滤波器。 验收：全频带/所有fraction幅相误差通过分配预算；不是仅整数时延通过。 |
| `target_complex_operator` | clk_rf | FULL_A | 目标复增益、2x2极化与Doppler混频；累加位增长和输出限幅。 验收：目标模型与本机校准分开；相位政策防止两程Doppler重复补偿。 |
| `dds_burst_control` | clk_rf | BASE | GSC起始、PW/PRI/count、包络、相位策略与LFM调谐字递推。 验收：脉间相参按定义；配置不在半个pulse内改变。 |
| `dds_nco_wrapper` | clk_rf | BASE | 48bit相位候选、16bit sin/cos，streaming PINC支持chirp；valid与包络同步。 验收：相位/频率方向及延迟对齐；不能把RFDC载频NCO当全部基带发生器。 |
| `awg_reader` | clk_rf, clk_ctrl | BASE | 读本地冻结H/V IQ表，PS只写inactive bank；CRC与提交后生效。 验收：输出不直接受PS DDR背压；不接受半表更新。 |
| `tx_source_mux` | clk_rf | BASE | MUTE/LIVE/DRFM/DDS/AWG选择及边界原子切换。 验收：全部模式走共用TX校准；单天线OTA禁用LIVE。 |
| `tx_cal_executor` | clk_rf | FULL_A | TX源MUX后、通道路由后按每DAC独立执行本机预补偿；八路基础复增益，矩阵/宽带多抽头另预算；所有源同一校准策略。 验收：校准表过期/无效不声称精密模式；DDS与DRFM相同参考面。 |
| `tx_interp4_wrapper` | clk_rf | BASE | 八条复数TX FIR：FIR75 L2后HB19 L2，125->250->500MS/s，1->2->4复SPC，全部clk_rf125MHz；增益与尾部显式。 验收：输入常值输出增益正确；插值滤波尾与RFguard一致。 |
| `rfdac_stream_adapter` | clk_rf | BASE | 规范4复样点转换为具体RFDC DAC I/Q interleaved；持续安全零值。 验收：ready后每拍供数；TVALID不被用作静音；欠载/未初始化不输出随机RAM。 |
| `tx_reference_analyzer` | clk_rf | BASE | 独立AUX_MID两路的TX耦合测量或冗余资格判断；全程采样，与主测量同时运行；默认不能作DRFM信号源。 验收：PA后耦合链需独立校准；采样时间归属实际TX事件。 |
| `rf_safety_interlock` | clk_rf, clk_ctrl | BASE | RX/TURNAROUND/TX/RECOVERY/SAFE，PA/T-R/限幅保护先后次序；硬故障锁存。 验收：Linux卡死/超时/PLL失锁均进入安全；时钟完全消失依靠额外物理关断条件。 |
| `config_shadow_commit` | clk_ctrl, clk_rf | BASE | AXI-Lite shadow、commit/ack、安全边界与系数版本pin；只允许inactive写。 验收：AXI AW/W独立到达，WSTRB正确；64bit/矩阵不撕裂；忙时明确拒绝。 |
| `fault_status_registers` | clk_ctrl, clk_rf, clk_mem | BASE | W1C故障、饱和/丢帧计数、能力位、时延表、构建ID、DMA状态。 验收：W1C与新事件同拍保留新事件；计数跨域使用快照。 |
| `coeff_reload_bridge` | clk_ctrl, clk_rf | FULL_A | PS装载inactive系数RAM并在安全边界按AMD reload/config协议提交。 验收：不能改写仍被旧回放descriptor引用的coeff；错误CRC/长度不激活。 |
| `fine_analyzer_selected` | clk_rf | OPTIONAL | 仅在吞吐预算允许时添加PL高精度测量；默认host C完成细分析。 验收：与回放A口有明确仲裁或复制资源；不能占用确定性回放口。 |
| `aux_source_controller` | clk_rf, clk_ctrl | BASE | 只切换ADC3/7独立模拟输入；MID量程不变；保留ADC/DDC/FIR持续运行。 验收：主六路不停止；切换settling/flush及source_epoch正确；无模拟硬件时不虚报成功。 |
| `tx_channel_router` | clk_rf, clk_ctrl | BASE | 一组H/V基线源映射到8DAC路径，随后各DAC独立TXCAL和FIR；闲置通道持续零；不是8套任意源或DRFM。 验收：每DAC源ID、增益/校准和静音状态可追溯，联锁不得绕过。 |

`rx_decim4_wrapper`/`tx_interp4_wrapper`替代旧D8/L8名称；旧sample_rate_gearbox不属于活动模块。native位序adapter仍保留。
描述符/归还FIFO是bank manager与reader的接口资源；不可假定每个语义连接标签都对应一个额外RTL文件。
额外PL精细分析不得抢占已接受回放的A口；默认交给host。RX功率可供检测/资格共用，避免重复实例化。
