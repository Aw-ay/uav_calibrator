# 08 FIR与整机资源预算

## 活动滤波器

主链125MS/s，全部运算clk_rf125MHz。RX使用19抽头半带D2再75抽头普通D2；TX逆序L2+L2。filters目录只含本方案的冻结整数CSV/COE及各向元数据。RX Q17，TX每级Q16。18bit系数/24bit内部数据/48bit累加为模型候选；IQ16显式舍入饱和。禁止中间为整齐总线而随意截位。

级联等效167个500MS/s抽头，群延迟166ns，响应跨度332ns，默认正常TX补零至少42个核心样点覆盖PL两级尾。实际校准、Farrow、RFDC和模拟guard另计。coeff响应约0.022862dB通带纹波、72.499263dB阻带；以reports/filter_metrics.json本次复算为准，不能当实测模拟性能。

## DSP算量

HB19有5对非零对称项＋可移位中心，FIR75有38个独立对称项。125MHz下每条实数路径需要10+38=48乘法单元。8RX和8TX各16条实数路径，共1536个优化FIR乘法预算。SSR半带优化不自动生效；实际对称、系数位宽、加法树和DSP列数须OOC。[A11][A24][A25]

| 条件 | FIR DSP | 含约定其他功能算量 | 再加25%规划额度 |
|---|---:|---:|---:|
| 稀疏且对称 |1536|1932|2415|
| 普通对称，不算HB专用节省 |1856|2252|2815|
| 稀疏不对称 |3040|3436|4295|
| 稠密不对称 |3616|4012|5015|

“其他396”包括一组所选H/V的RXCAL8、分数延迟252、目标矩阵16、多普勒8、8DAC基础TXCAL32、RX功率16、档间相关24、AUX相关16、DDS额度8、低速运算额度16。63tap分数延迟只是预算占位，未证明满足全部±50MHz/fraction误差；低阶Lagrange不得默认宽带平坦。高阶复数FIR/矩阵校准会增加数百甚至上千DSP，见resource_budget.json的敏感性表。

ZU27DR参考4272 DSP。首版规划约2400～2900、控制目标3000以内；不是综合预测上界。低PRF不减少已实例化的连续FIR资源，RX/TX未按半双工假设共享硬件。DMA/CRC/仲裁按LUT/FF/RAM实现记0DSP，但它们不是0资源。[A19]

## RAM规划

捕获RAW2MiB的双时钟宽度映射约512 RAMB36；可选quality64、AWG64、记录FIFO20、其他100～160额度，合计760～820/1080。PS DDR128MiB接收池不占PL BRAM。4组全部8bank时Capture即1024块，未留其他资源，不视作可直接配置。URAM80块是另一类资源，双时钟架构不能直接替换。[A19][A22][A29]

LUT/FF/布线/时序/功耗没有综合证据，不由DSP比例推断。RFDC硬核数字处理不额外重复计成软PL FIR，但IP wrapper仍有资源。Gen1 ADC12bit/DAC14bit不等于IQ记录16bit的模拟有效精度。
