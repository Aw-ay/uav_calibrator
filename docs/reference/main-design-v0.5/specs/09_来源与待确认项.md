# 09 来源、实现门与未确认项

2026-09-11，v0.5。网络能力条款按官方文档复核，不因此升级用户工具版本。当前只有规格/数值/行为验证，没有Vivado/Vitis/板级证据。

## 材料优先级

本轮对话中明确的125MHzFIR/200MHzDMA和四组轮换bank等决定已合并为活动合同。v0.3主包保留全部原始文件于provenance原ZIP；v0.4滤波包是系数与模型来源；各次审查报告为历史证据，不覆盖本版。未重新读取GitHub；MATLAB旧提交不是本次125MHzSSR的硬件golden。

## 当前实现门

| 未确认项 | 不得自动填充 |
|---|---|
| ZU27DR完整part、板卡/PCB版本、BSP | 设计参考器件不等于选定板卡；旧AXRF47 ZU47信息不套用 |
| Vivado/Vitis/Linux/IP版本 | 不凭最新在线文档升级 |
| ADC/DAC/PL时钟实际路由、PLL、SYSREF、MTS | 4GS/s只是可核对速率目标 |
| RFDC Tile/Block/native word及模拟Nyquist区 | 不猜端口或引脚 |
| 模拟增益顺序和阈值/校准 | HIGH名字不证明最高增益；未确认时不ARM精密资格 |
| detector最大延迟和所有pipeline latency | 32点仅模型例子，实际字段空 |
| 分数延迟架构与宽带误差预算 | 63tap只算资源，不能作为已验收算法 |
| BRAM宽度/端口、描述符CDC和复位 | 数值模型不能证明RAM时序/亚稳态 |
| 实际DMA、DDR、SSD、网络吞吐 | 2.4GB/s仅场景假设；保留丢失统计 |
| RF开关/PA极性、断钟关断、模拟校准 | 软件和数字零不能代替物理安全 |

上述门不阻止编写规范与核心测试，但阻止宣称板级工程已可用。参考C00/C02的开发任务和contracts/verification_matrix.json实际验收项。
