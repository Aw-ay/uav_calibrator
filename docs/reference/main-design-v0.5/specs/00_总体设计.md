# 00 总体设计（v0.5活动基线）

本稿已合并此前各轮讨论；规格已统一不等于RTL已实现。数值主合同：`contracts/system_contract.json`。

## 1. 系统分工

阶段A为仪器本体，PL承担连续流和确定性TX，PS承担时钟/RFDC/MTS、校准版本、任务和DMA/存储；阶段B由PS使用实际导航/姿态观测形成未来有效的参数；阶段C在地面host完成未知参考多径、精细测量和不确定度解算。不得把仿真真值放入实测sidecar，不将host盲优化直接反馈到正在发射的任务。

参考MATLAB仓库与旧提交保留在system_contract，仅作来源。旧500→62.5算法不能未经适配作为当前golden；本次未重新读取仓库。混合架构保持：BD搭PS/RFDC/AXI/DMA，RTL管真实时间、捕获对象/所有权，适当算子使用AMD IP。

## 2. 三条数据通路

```text
RFDC内部DDC后500MS/s复数×8
 → native适配/epoch检查（4SPC@125MHz）
 → HB19 D2 → FIR75 D2（全125MHz，4→2→1SPC）
 → 显式舍入 → 四组H/V连续流
       ├─ 检测与资格统计（不串接成波形开关）
       └─ 多bank循环预填/脉冲捕获 → RAM冻结 → 统计完成/共同选档
                                                    │
                ┌───────────────────────────────────┴────────────┐
                ▼                                                ▼
 A口64bit@125MHz本地读                             B口128bit@200MHz读
 → RXCAL → 分数延迟 → 目标矩阵/多普勒                → 记录级仲裁/环绕/对齐
 → TX源选择(DRFM/DDS/AWG/经许可LIVE)                 → Header/IQ/CRC
 → 八DAC路由 → 每DAC独立TXCAL                        → AXIS FIFO → S2MM SG
 → FIR75 L2 → HB19 L2（1→2→4SPC@125MHz）            → PS HP0 → DDR接收池
 → DAC adapter → RFDC内部插值/混频 → 物理DAC/RF
```

八路独立FIR历史持续工作。采集端不能等待DMA，上传端允许排队，已接受的TX样点时间不能被DMA背压移动。AUX回环来源不得自动重放；回环可与主六路数字采集并行，但主模拟输入在半双工TX期间的物理有效性仍由联锁/前端决定。

## 3. 速率与时钟

| 边界 | 每通道复数率 | 复SPC | 逻辑位宽/通道 | 时钟 |
|---|---:|---:|---:|---:|
| RFDC规范输入 | 500 MS/s | 4 | 128bit IQ16 | 125 MHz |
| HB19输出 | 250 MS/s | 2 | 候选96bit IQ24 | 同一125 MHz |
| FIR75输出 | 125 MS/s | 1 | 候选48bit IQ24 | 同一125 MHz |
| 最终记录 | 125 MS/s | 1 | 32bit；HV打包64bit | 同一125 MHz |
| TX插值结果 | 500 MS/s | 4 | 128bit IQ16 | 同一125 MHz |
| 冻结记录AXIS | 记录字节流 | 非采样率 | 128bit | 200 MHz |

不再存在活动250MHz FIR计算域。名义相等的两根125MHz时钟不一定同域，要求RFDC/算法/A口/DAC规范接口使用同一合规clk_rf。控制100MHz、记录200MHz保留经过验证的CDC。4SPC是同一信号连续4个时间点，不是4条独立通道；RFDC16bit word也不等于复样点。[A01][A03][A10][A11]

## 4. 器件范围

ZU27DR Gen1作为本轮资源与速率参考目标，不猜测具体板号/速度级/封装/preset。ADC4GS/s内部D8→500MS/s是待板级确认的目标；PL D4→125MS/s已作为设计基线。TX按PL L4后500MS/s、RFDC L8到4GS/s目标，不采用Gen3 L16/8GS/s配置。2.8GHz的Nyquist区、混频方向、镜像和模拟滤波须实测。[A05][A19]

## 5. 功能档

`BRINGUP_1CH`用于最小测试，不能当作八路产品验收。`BASE_8ADC_HV`八ADC全开、三档共同选档、独立AUX、默认四bank/组。`FULL_A_HV`在同基线上加入经过验证的本机校准、分数延迟、单目标H/V极化与多普勒。CAPABILITIES只报告实际编译并验证功能，设计目录不是功能实现证据。

每DAC滤波8路不等于8套独立DRFM/AWG。基线是一组所选H/V目标引擎，路由后每DAC独立基础校准。高阶宽带校准、多目标、PL FFT/盲多径/SIC/DPD、高速网络、PLDDR与MM2S都要单独资源/精度评审。

## 6. 安全和计量

RAW为PL_FILTERED_RAW而非ADC原码；不同量程scale/校准不可混用，校准副本不改写RAW。GSC2ns是单位，不是物理RF门2ns准确度。单天线OTA默认禁止LIVE。任务时刻、RAM读完、TX流水排尽、实际RF完毕、DMA完成和host验证分别记录。PA/TR默认态和断钟安全由实际电路保证，软件不得绕过。
