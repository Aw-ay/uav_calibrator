## 数值与合同复算
`python tools/verify_all.py`运行当前合同/ABI/系数/定点/队列/行为测试，并生成明确的报告。数值输出不能声称真实125MHzSSR II或真实DDR服务率已经通过。

## 必须补充的真正硬件实验
四FIR类型实际ZU27DR OOC；双时钟非对称RAM和读在途信用；RFDC原生I/Q计数全lane；MTS重复启动；主三档冻结/选档/释放＋独立AUX并发；DMA/存储停顿；DRFM因果与滤波尾；复位隔离旧reader；实际PA/TR断钟安全。
