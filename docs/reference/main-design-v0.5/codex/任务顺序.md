# Codex实施顺序：v0.5唯一活动基线

本表是未来开发任务，不是已完成任务。先读根AGENTS.md、contracts和specs/14。板级未知门必须显式解决，但可先实现与板卡无关的合同/参考测试。

| 任务 | 产物 | 交付门 |
|---|---|---|
| C00 板卡与工具 | 完整ZU27DR part/PCB/BSP/时钟与RFDC映射，记录实际工具/IP版本 | 不把旧ZU47 preset套用；Gen1能力及PLL/Nyquist合法 |
| C01 ABI/参数 | 执行tools/generate_contracts.py，真实CSR和descriptor/record解析实现 | generated常量与JSON一致，ABI5，字段无重叠；CRC/变长长度测试 |
| C02 FIR/RAM/DMA OOC | 四类125MHzSSR FIR、A125/B200 RAM、200MHzDMA XCI与OOC报告 | 对称/零系数、位宽、II、pipeline、DSP/BRAM及时序证据；预算不是报告 |
| C03 平台BD | PS/RFDC/CSR/DMA/测试流/安全零，按bd_connections | S2MM和SG都到HP0；clk_rf无250域，默认不TX |
| C04 时间控制 | CSR shadow/commit，GSC4tick、事件快照、协调reset | AW/W/WSTRB/W1C，64bit不撕裂；epoch不是停止reader的替代 |
| C05 八路RX | native4复SPC→HB19 D2→FIR75 D2→1SPC，fixed_round_sat | 8独立历史，四lane过载，全部125MHz；RFDC内部D8未误改 |
| C06 bank/检测/选档 | capture_bank_manager和RAM，主三档原子触发，FROZEN_PENDING与资格 | 四bank同功能广播预填/轮换，检测回溯、满长/超长/迟到EOP；全无效不TX |
| C07 上传reader/帧 | record级仲裁、奇数carry、formatter/CRC，归还CDC | 128bit@200，inflightRAM信用，oddIQ+trailer与TLAST正确，旧ACK拒绝 |
| C08 裸机DMA | 普通SG及DDR槽，计数数据闭环 | 实际length/cache/对齐，用户未release不能复用；不是cyclic循环覆盖 |
| C09 TX源和FIR | H/V DDS/AWG源、8路路由后TXCAL，FIR75 L2→HB19 L2 | 同125MHz1→2→4SPC，Q16增益，idle零，连续尾；不是8独立波形源 |
| C10 本地DRFM | frozenA口reader、任务合法性、时刻反推、联锁 | DMA零服务不挪已接受TX；pretrigger参考位置、正常尾及故障安全 |
| C11 最小台架 | Capture/DDS/cableloopback/经许可LIVE/bufferedreplay | 实际RF时延/输出/联锁/MTS重复启动，不以软件计划代替 |
| C12 Linux | 匹配DMAengine/驱动、mmap/poll、record服务 | 单所有者、变长长度、并发DDR/SSD/网络压力和drop记录 |
| C13 校准 | 基础RX与每DACTXCAL、系数inactive提交/pin | 不双补偿，实际增益顺序/阈值有效；高阶校准另预算 |
| C14 分数与目标 | 选择并验证宽带fractional结构、目标矩阵/Doppler | 全±50MHz及所有fraction误差；63tap预算不等批准算法 |
| C15 AUX计量 | 独立输入开关/settling/42PLflush、实际TX触发、MID冗余 | 主六路不断，loopback不重放；数字并行不等半双工RF全有效 |
| C16 B/C与可靠性 | 实际导航sidecar、时延/scale版本、host精分析 | 无真值/无即时盲反馈，记录/RAW/任务所有权完整 |

每步附确实运行的工具命令和日志。核心RTL并发要明确每个时钟、端口、latency、valid/ready、参数生效点及消费者引用。占位模块不能声明已完成，未运行项保持NOT_RUN。PL FFT/SIC/高阶全矩阵/多目标/额外bank必须先更新资源和测试。
