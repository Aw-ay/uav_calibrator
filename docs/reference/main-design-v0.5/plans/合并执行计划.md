# v0.5主包合并计划

目标：将已讨论的工程接口与缓存/DRFM决策合并进v0.3主合同，而不是另做补丁包。

范围：125 MHz RX/TX FIR与核心、200 MHz DMA、四组四bank、选档后记录、Gen1 ZU27DR参考目标、资源预算。
硬件未验证的封装/BSP/IP映射/量程增益顺序保持未确认，不补造。

1. 对原主合同运行新版断言，记录预期失败。
2. 更新全部JSON主合同，补充bank、选择策略、回放任务、DMA所有权、时延和资源合同。
3. 更新总体/ADC/存储/DMA/DAC/PS/验证文档与Codex任务；删除活动250MHz gearbox及旧D8滤波计划。
4. 复制已交付HB19与FIR75整数系数，RX与TX小数位分开标注。
5. 合并现有Python参考模型，增加容量拒绝、TX补零尾部、四bank广播轮换和一体化合同测试。
6. 生成C/RTL常量与ABI偏移，编译检查C；重算频响、预算与单DMA脉冲服务。
7. 检查链接、ABI偏移、寄存器地址、唯一测试ID和旧配置残留；保存实际测试结果。
8. 原始输入归档，生成逐文件变更/来源/哈希，重新解压最终ZIP并复测。

本次不生成虚假的可综合RTL、XCI、XSA、ELF或bitstream。
