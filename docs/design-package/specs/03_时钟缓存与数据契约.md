# 时钟、RAM端口、数据与确定时延合同

## 1. 时钟表

| 名称 | 候选值 | 用途 | 时钟来源 |
|---|---:|---|---|
| clk_rf |62.5MHz|规范8SPC输入、D8输出、检测/回放/DDS/TX|共同外部PL参考经合法Clocking Wizard |
| clk_ctrl |100MHz|PS HPM、AXI-Lite、状态/事件读取|PS FCLK候选 |
| clk_mem |200MHz|冻结RAM B口、formatter、DMA、HP0|PS FCLK候选 |
| clk_math |默认无|必要时局部运算复用|仅经批准，由相干PL参考派生 |

clk_mem和clk_ctrl不参与模拟样点的物理时间定义。它们与clk_rf之间通过经过验证的FIFO/握手传递描述符和事件。

在MTS模式，RFDC AXIS时钟应由外部PL参考产生，不从RFDC自身clk_adc/clk_dac输出反过来构成同步依据。[A06] 若板卡只能提供其他PL频率，则应根据实际PLL/MMCM可实现倍分频改变board profile，不修改核心采样率凑数。

SYSREF与1PPS不同。SYSREF用于转换器内部对齐，须满足ADC/DAC分频及PL采样时钟公因子约束，并在MTS时提供符合要求的周期脉冲；1PPS用于外部时间事件。[A07][A09]

## 2. 复位与启动

```text
POR/物理安全零值
  → PS最小初始化
  → 配置并确认板级参考/PLL
  → 释放各域同步reset
  → RFDC初始化
  → ADC MTS + DAC MTS
  → NCO/QMC同步
  → 校验通道/epoch/系数
  → 装好DMA缓冲并开始接收
  → READY（仍不自动TX）
  → 人工/任务批准ARM
```

物理RFDC数据接口reset后必须重新建立必要同步条件。PL软清空capture不等于复位整条AXI，也不应随意清GSC。真时钟不连续则增加epoch并使待回放描述符失效。

SmartConnect连接的AXI主从端口不能分别无协调复位；遵循共同复位重叠规则。[A15] 单个算法状态机软复位应保持AXI slave协议壳正常，先停任务再清状态；不能向总线留下未响应事务。

## 3. GSC和时延账本

- `gsc_base`：uint64，以500MHz复样点刻度计数；每clk_rf加8，八lane编号为base+[0..7]。
- 输出核心样点的间隔是8ticks=16ns。
- RFDC/DDC、PL FIR、整数/分数校准、replay reader、矩阵、TX FIR、DAC/RF分别有自己的latency字段。
- 145tap RX FIR群时延72原生复样点=144ns；IP流水和存储读准备另记。
- `sample_time`说明信号对应时刻；`available_time`说明何时能使用。二者不得互相替代。
- GSC读出使用快照，不能PS先读低32bit再任意读高32bit造成跨回卷撕裂。
- PPS普通同步器的捕获误差按实际clk_rf和电路计算；不能因为GSC单位2ns而承诺PPS2ns。

静止场景设备目标延迟为2(Rv-Rs)/c，移动场景为(2Rv-Rf-Rb)/c。PS基于可知导航计算命令，PL只执行绝对目标时刻与已确认固定延迟。小于实际data_ready与守护窗口的命令明确拒绝。delay>PRI按所有相关时隙检查，不能单凭超过PRI判定非法。

基线CORE只能在16ns离散点供样；2ns或更细目标通过fractional waveform delay表示，并不表示RF门在任意2ns边界开关。门控和数据插值的物理意义必须分开。

## 4. RAM端口的可实现结构

每个range每个bank：

```text
A口：64bit ×8192 @62.5MHz
  bank采集中 → 写
  bank冻结后 → 本地回放读
  同一个bank在同一拍不会既采又回放

B口：128bit ×4096 @200MHz
  只对冻结bank执行DMA读
```

该方案不需要一块双口RAM承担“写+回放+DMA+Fine”四个端口。不同bank分别是独立存储，因此一个bank采集时另一bank回放正常。对于额外PL Fine Analyzer，要明确与A口仲裁并证明不破坏回放deadline，或增加单独副本；默认精细分析留host。

BRAM非对称端口必须通过具体IP输出和仿真证实。环形frame可从任意64bit样点开始，DMA128bit地址自然对齐可能读出前一/后一sample；frozen_frame_reader必须完成carry、边界对齐和环绕，不能只把读地址右移一位。

禁止活动bank的B口读取正在写的地址；描述符只能在最后写入已完成后跨域发布。释放ACK包含bank_id+generation，拒绝陈旧ACK。

## 5. 预触发不能靠瞬间memcpy

拟议基线：空闲且可用bank的A口持续接收预触发环形流（可对FREE/ARMED bank广播），只有预填达到pre_samples才允许ARM。触发时选一个已ARMED bank继续写整脉冲，冻结start/end指针；其他可用bank保持预触发准备。

这避免“触发那一拍同时复制125个预触发样点并写当前样点”的不可能操作。若采用共享preFIFO+后台拷贝，则必须另行给出真实端口和速率证明。

## 6. 容量与bank生命周期

8192×64bit=64KiB/range/bank；三档两bank=384KiB RAW。三档八bank=1.5MiB RAW，不含AWG/校准/FIFO/参考监测。

120us脉冲+2us前+2us后=124us，对应7750个62.5MS/s样点；8192仅剩442点约7.072us裕量，EOP、滤波尾和最大异常必须计入。不能把8192说成任何长尾都够。

状态：`FREE→ARMING→ARMED→CAPTURE→FROZEN→RELEASE→FREE`。冻结后保存replay_ref和record_reader_ref。先完成的一方不得释放另一方需要的数据。回放过晚、DMA堵塞或无free bank时，drop new capture并保留丢帧事件，不覆盖旧bank。

所需bank数由实际最坏保持时间估算：`N >= ceil(T_hold/PRI)+安全余量`，并通过事件仿真确认。只保存脉冲不需要5ms连续移位RAM，但很多待发脉冲会同时占bank；“两bank支持任意5ms延迟”不成立。

## 7. DATA与EVENT分离

DATA：每个选中range一个完整记录；诊断模式三个记录共用pulse_id。每个record以一次TLAST结束。格式在frame_format.json中定义为128B头、N×8B载荷、可选16B CRC尾。

EVENT：基本PDW、开始/完成/中断、overload、drop与fault使用独立小队列。建议512bit一条、总1024条起步；跨域每个生产域独立FIFO再汇聚。PS每条先LATCH、读16个32bit字、最后POP，读过程保持稳定。IRQ按水位和关键故障触发，避免每样点/每脉冲中断。

CAPTURE_PDW只包含硬件实际在线得到的内容；C的FINE_PDW稍后按pulse_id合并。上位机最终ToA尚未计算时，不能放进已发header假装是final。

## 8. DMA服务预算与生命期

- 冻结RAM B口与formatter在clk_mem；不必再把每个payload先跨一个62.5→200的FIFO。本设计CDC发生于冻结descriptor和release ACK，数据由双时钟BRAM的冻结区读取。
- AXIS FIFO只作为200MHz流的背压缓冲，典型4096×128=64KiB；默认非packet-mode，不要求整个record必须预存后才吐出。
- 128bit@200MHz理论3.2GB/s；记录路径持续能力须在PS/Linux并发下测量。
- S2MM与SG两个memory master都要接DDR，不能只连S2MM忘掉SG。
- DRE关闭时所有BD/buffer地址正确对齐，TLAST/TKEEP控制真实长度。建议128KiB槽、256槽起步约32MiB；实际需要按内存和中断策略确定。
- DMAengine标准接口下，变长RX packet的实际长度/residue支持随驱动而异，客户端必须验证所选驱动/BD模式，交叉检查header长度与硬件完成状态。不能只凭预提交buffer大小当有效长度。

状态必须区分：CAPTURED、RECORD_QUEUED、READER_DONE、S2MM_BD_DONE、PS_RECEIVED、HOST_VALIDATED。RAW bank可在数据已安全移交下游FIFO且本地回放结束后释放，但这不等于DDR/host已经收到；传输故障必须记录lost record，不伪造成功。

## 9. 位宽与坐标基

规范内部H/V sample位序：bits15:0=H_I，31:16=H_Q，47:32=V_I，63:48=V_Q；小端载荷顺序相同。lane0最早。RFDC实际位序与该规范之间必须有显式adapter。

校准和目标矩阵每个pulse冻结。PSD、功率与幅相单位在scale_id、reference_plane、filter_id及calibration_id中确定；归一化分析副本不覆盖RAW。

C做多径需要足够捕获窗口及高频过载旁证；若只上传选中档则不能事后还原另外两档。缺导航、时钟或TX监测字段，PS必须写UNKNOWN，不能从仿真真值补齐。
