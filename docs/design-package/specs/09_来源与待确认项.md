# 来源、范围与待确认项

本设计稿日期：2026-09-08。状态：DESIGN_PROPOSAL。没有运行 Vivado/Vitis，没有生成可下载 bitstream/XSA/ELF，没有执行板级测试。

## 材料层级

1. 已确认的软件来源：MATLAB `4gps`，提交 `3065469792e47b500aeb8a9f8ace1fd513948fd9`。本次重新读取的 README 已增加 OTA、阵列及宽带校准；不能继续沿用早期“这些模块不存在”的旧审查。
2. 用户资料库的 AXRF47 手册：`328aeee1-35a7-4f91-ada1-deee761f3bed.pdf`，其中第7页写 ZU47DR-2FFVE1156I，PS 4GB/PL 2GB DDR4；第14页写 LMK04828、19.2MHz OCXO；第27页写 M.2 使用 PS GTR。手册存在不一致的个别单位，不将示意参数替代原理图/BSP。
3. 前面对话同时出现 ZU27DR，不能据此认定本次必然选择 ZU47DR。本文对算法内核固定接口，对板级部分只给候选配置。
4. 下列 AMD 官方文档用于校核接口和能力。网络文档可能更新；实施时以选定 Vivado 自带 IP 版本及匹配文档为准。
5. 本文所有缓存数、总线频率、位宽、地址和DMA槽数中未注明来源的值，都是设计建议，不是实测能力或验收通过值。
