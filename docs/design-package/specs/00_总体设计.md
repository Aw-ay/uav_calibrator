# 总体设计：一个平台壳层、一个可复用PL核、一个PS软件栈

## 1. 目标与来源边界

继承既有讨论：阶段A完成本体；阶段B加入机载观测和扰动补偿；阶段C承担未知参考波形的详细测量、多径辨识与计量解算。A/B的物理模型不是要搬进FPGA的电路，C中的盲优化也不进入默认PL。

最近重新读取 `4gps` 当前提交已为 `3065469792e47b500aeb8a9f8ace1fd513948fd9`；其500M→62.5M采样链继续作为算法依据。新增的OTA/阵列/宽带功能是功能模型，仍不能当作板卡接口或时序验证。[R01]

推荐采用混合架构：BD负责PS、RFDC、时钟复位、AXI和DMA；自研RTL负责真实时间、脉冲对象、缓存所有权和回放；可重复DSP算子用AMD IP封装。不要把每个乘法器都堆在BD，也不要自己重写全部AXI/DMA/存储控制器。

## 2. 必须保留的功能层

| 层 | 责任 |
|---|---|
| PL连续流层 | RFDC适配、前端过载标志、FIR、检测、资格统计与捕获，不能背压ADC |
| PL确定性TX层 | 本地回放、DDS/AWG、增益/相位/极化、TX校准、插值和安全零值 |
| PL分组上传层 | 冻结帧读取、描述符、header/payload/trailer、DMA与事件队列 |
| PS设备层 | 时钟芯片、RFDC/MTS、驱动、校准系数、任务调度、数据交付、存储网络 |
| B适配层 | 导航/姿态/遥测对齐，由PS形成带生效时刻和质量的系数/命令 |
| C上位机 | 原始IQ精分析、未知参考多径、OTA/雷达解算、不确定度与拒收；只提议下一任务参数 |

不在本期默认增加：完整PL FFT/脉压、盲均衡、多目标、数字SIC、全双工、PL DDR长时移、10G/100G、R5专用运行时。后续确有需求时再评审。

## 3. 全链路逻辑

```text
时钟芯片/共同参考 ──> RFDC ADC/DAC、PL采样时钟、SYSREF
                    └─> PS执行MTS和NCO同步

外部信号/天线 ─> H/V模拟三档 ─> RF-ADC
  ─> RFDC DDC/8 ─> native adapter ─> 前抽取过载统计
  ─> 三套FIR D8(每套4个实数路径) ─> 62.5MS/s H/V×3
       ├─> 在线检测/整脉冲资格 ─> EOP共同选档 ─> CAPTURE_PDW
       └─> 多bank RAW环形/脉冲缓存
                 ├─ A口：本地回放读取 ─> RXCAL ─> delay/target operator
                 └─ B口：冻结帧读取@200MHz ─> formatter ─> DMA ─> PS DDR

本地回放 ─┐
DDS/LFM ──┼─> TX Source MUX ─> 共用TXCAL ─> PL插值 ─> RFDC DUC/DAC
AWG RAM ──┤                                              └─> RF功率链
LIVE ─────┘                                                   └─>输出
                                                           耦合参考ADC
                                                               └─>TX监测

PS HPM ─> CSR/命令/校准/AWG装载
PL事件 ─> CDC队列 ─> PS ─> 本地文件/地面站/阶段C
```

高精度处理时的LUT/FIR/矩阵属于本机误差修正，不把目标散射矩阵、天线姿态矩阵和本机校准混成一个无法追溯的参数。初期可按数学等价关系合并运算，但必须保存原始参数、复合算法和时延版本。

## 4. 三个配置档，而不是三套工程

- `BRINGUP_1CH`：一ADC/一DAC，保持同样速率和接口；模拟三档未接时，range固定并标记未验证。验证Capture/DMA/DDS/LIVE/REPLAY。
- `BASE_3R_HV`：六测量通道、共同选档、两bank起步、基础校准/回放、PA安全联锁。
- `FULL_A_HV`：两参考通道、完整本机校准、分数延迟/目标极化、更多bank和宽带执行器按资源与模型评审开放。

B/C不需要重新造BD。PS增加观测和系数服务，host增加C处理。实际编译功能由只读CAPABILITIES报告；不能使软件菜单看起来有某功能就视为RTL已完成。

## 5. 速率合同

| 边界 | 复样率 | 每拍复样点 | 逻辑宽度（每H/V对） | 时钟 |
|---|---:|---:|---:|---:|
| 规范化RFDC输出 | 500MS/s | 8 | 512bit | 62.5MHz |
| FIR D8输出/缓存 | 62.5MS/s | 1 | 64bit | 62.5MHz |
| DMA冻结读流 | 非固定采样率 | 每beat两个时间点 | 128bit | 200MHz候选 |
| DDS/DRFM/TXCAL | 62.5MS/s | 1 | 内部宽度按定点模型 | 62.5MHz |
| PL TX插值输出 | 500MS/s | 8 | 512bit | 62.5MHz |

每个polarization的IQ16复样点32bit。三档前端总规范位宽1536bit。native RFDC是否能直接提供对应布局由Dual/Quad、真实IQ模式和FIFO words配置决定。[A01][A02]

主DSP不必统一250MHz，但不能宣称“时钟变低必然DSP资源变少”：输入FIR仍需吞吐500MS/s；SSR需要并行乘加。定点与综合报告决定能否在62.5MHz完成。必要的125/250MHz局部运算域只在单独验证后采用。

## 6. 不能漏掉的TX速率闭合

通用关系为：`F_DAC = F_core × L_PL × L_RFDC`（额外IMR等必须另计）。

Gen3候选：`62.5M × PL8 = 500M IQ → RFDC16 → 8GS/s real DAC`。在IQ→real模式下，规范目标是8复样点/拍，即16个16bit字/拍，256bit每DAC流。2.8GHz处于8GS/s第一Nyquist区，但实际器件、PLL和模拟输出网络必须验证。[A04][A05][A20]

这是本稿提出的候选，不是此前已确认参数。ZU27DR Gen1不能套用8GS/s/16倍配置。若实际板使用其他DAC速率，应重新确定PL插值率，不得用删样、重复样点或错误时钟凑合。

## 7. 计量与安全边界

- GSC的2ns是记账单位，不是62.5MHz逻辑能直接给出2ns边沿或2ns授时准确度。
- RAW上传保持仪器原始可测信息；C只在有校准和辨识依据时修正。
- 只有低时延硬件执行器对当下脉冲起作用；PS/host慢算法只更新未来任务。
- 单天线半双工中，LIVE默认非法；电缆/隔离端口模式必须显式选择并授权。
- PA和T/R的上电安全态必须由实际引脚极性、外部电路和无时钟场景共同保证。BD里一个mute方框不足以覆盖断钟或掉电。
