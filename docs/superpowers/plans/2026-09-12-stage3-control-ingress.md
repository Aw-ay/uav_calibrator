# 第三阶段控制与采样入口

用户已授权当前任务内继续，不使用子任务或窗口。

按顺序实现：
1. PS AXI-Lite事务邮箱：32位字寻址影子区、操作码/长度/序号/CRC32C、提交、状态及结果区。单条在途；影子修改不影响已提交请求；RF端消费后返回明确结果，不能把CDC收取当执行成功。生成SV/C同源偏移。
2. RF控制适配：静态配置映像与执行动作分离，原子配置只能在停用且业务排空时切换；校准/profile/回放/DDS/AWG使用现有模块的实际应答；硬件绑定信号独立于软件配置。
3. 原生ADC输入经实际FIR，时间与质量同步推进；物理H/V映射与时钟/MTS/过载有效性由外部板级绑定输入。检测、因果噪声快照及窗口质量驱动真实采集事件。
4. 组合控制、入口和第二阶段数据顶层。基于实际MMIO与原生ADC样本仿真；保留硬件绑定无效时零码；加入回归、XSim及综合报告。板级PS/RFDC IP物理连接和布局布线仍需完整约束后验收。
