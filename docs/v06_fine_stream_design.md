# Fine 单遍局部缓存与统计累加阶段

2026-09-30，D07 子阶段。新增32样点缓存、H/V分段统计累加器，以及单遍因果调度模型。
**完整 Fine Engine 尚未完成或接入仪器核心。** 现有 CORDIC、两个新模块均是独立硬件构件。

## 数学、调度与硬件边界

批处理真值仍为 tools/fine_reference.py / fine_fixed.py。新增 tools/fine_stream.py：

- SampleCache 的 observe/clock 分离，严格以当前状态决定握手和读取，生成逐拍 RTL 期望。
- FinePass 每拍至多接受一个当前可用 H/V 样点，没有整个 RAW 的存储或读取接口。
  等 k+4 已到达才启动 k-3..k+4 的边沿拟合；仅在确实接完 RAW 后使用末端裁剪。
  上升选第一合法边沿、下降选最后合法边沿，额外交点计入质量位。
- 边沿数值服务使用已验证整数内核，延迟可配置；忙时停止接收与退休样点。
  这是显式停顿的因果调度证明，不是尚未实现的边沿算术 RTL 的逐拍等价证明。
- 缓存满32点才退休最早样点，EOF完成边沿后排空。未知下降沿时只累计保证属于body的前缀；
  无法决策时有断言，不能偷读未来或事后修正已累计内容。最终边沿无效则丢弃暂存统计。
  70组生成输入的边沿结果、H/V各8段的完整统计量、body能量及H/V相关量与批处理一致。
  本阶段调度模型覆盖已知noise和有效source默认场景，生产端坏来源/身份取消仍需引擎控制器处理。

32点界限的保守说明：边沿搜索在粗边沿±8内，最后局部样点不晚于粗边沿+12；
下降端最早可能的stable终点为粗边沿-12。32点队列的31点后视余量覆盖这24点范围。
计算任意多拍只增加停顿，不增加缓存深度。EOF/短窗/边沿重叠使用同一规则并单独验证。
这不代表整机处理吞吐已达标，Fine作业调度仍需计入求解和停顿预算。

## HDL 对应

| 模块 | 输入与输出 | 已验证边界 |
|---|---|---|
| fine_sample_cache | 自然B128+mask → 顺序64bit H/V样点；按索引注册读取局部样点 | 32逻辑样点、双lane写入、单样点退休、响应背压、输入身份/首尾校验、取消 |
| fine_segment_accumulator | H/V样点+body掩码+分段ID → 两极化各8段及H/V统计和 | 16个16bit乘法，33bit复乘结果，48bit复数和、46bit能量、32bit双倍中心和、15bit计数 |
| fine_cordic（前阶段） | 48bit复数和 → Q31相位 | 本阶段重跑既有逐位/握手测试 |

缓存按自然word的低lane、高lane顺序处理有效样点，不在Fine前跨word重排。
奇数起点满16384逻辑样点恰需8193个自然B字，绕回时重复首物理word属于一次自然遍历的边界行为。
上游reader的信用FIFO属于额外传输缓冲，与Fine局部32点容量分开核算。
缓存两写入和查询/退休读端口当前综合成寄存器，不宣称使用BRAM。

累加器每拍可接收一个逻辑样点，暂停输入不打断逻辑邻接；body掩码为0则打断该极化的邻接链。
H/V交叉只在两者body同时成立时累计，能量分开保存，保留不同增益的正确相干性检查依据。
两个算术级和累加级排空后才产生持有型结果；释放前拒绝新任务。
连续输入的前样点能量使用流水线前递，已覆盖连续流、气泡与带符号极值。

RTL组合TB将已知body掩码和分段ID注入累加器，检查reader→cache→accumulator运输与算术。
**该TB不证明边沿控制器已存在**；单遍边沿决策由FinePass独立核对，后续必须把控制器落到RTL。
缓存取消只取消局部状态；B reader完成在途响应排空后才能释放bank引用。
当前组合TB验证该顺序，生产级三引用和B仲裁仍为D08工作。

## 验证与综合

- 10个相关测试入口通过，包括既有5个Fine数值/相位套件、4个新套件及B128 reader回归。
- 缓存63,806拍逐项对照：奇偶起点、1/2/3/31/32/33/16384点、随机停顿、索引查询、非法输入、复位/取消。
- 因果模型4项测试、70组输入：完整16384点、短窗、±8偏移、振铃、多交点、随机IQ、低SNR；显式257拍求解停顿。
- 累加器16,558点、6个任务：全部统计字段逐位核对，单拍连续流、气泡、满窗负极值、结果持有、管线取消、非法索引。
- reader/cache/accumulator组合在RAM模型延迟1/2/3拍下通过，各自覆盖8193请求、缓存满停顿、40个取消位置和响应排空。
- 同一组合TB在Vivado2025.2 XSim通过（RAM延迟模型1拍，不是新一轮实际BMG/IP延迟测量）。

200MHz、ZU27DR -2工业级、Vivado2025.2 OOC：

本阶段未重跑完整核心；上一全核心综合仍只覆盖已接入D05在线统计，Fine新构件不在活动网表中。
