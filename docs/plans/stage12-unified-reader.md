# 第十二阶段：统一 EVENT 软件读取器

属于第九至十一阶段的统一 EVENT 集成批次。本阶段仅增加可移植 PS 软件，不修改 RTL、顶层或时钟约束，验证采用定向测试、相关回归和 A53 编译，不重复 Vivado 综合。

- [x] 定义 fetch/inspect/pop 两阶段接口，保留原采集读取 API。
- [x] 先运行新测试，因实现文件缺失出现预期失败，再完成实现。
- [x] 识别采集 PDW / RF 故障聚合格式；未知及错误格式保留原始记录，由调用方决定是否显式丢弃。
- [x] 覆盖读取失败、独占读取、POP 不确定结果；后者必须保留记录并禁止自动重试。
- [x] 使用真实 RTL 仿真产生的记录驱动 C 寄存器模型，完成相关回归和 A53 构建。
- [x] 审查并归档证据，在阶段边界暂停。

约束：整个 fetch/处理/pop 期间单一软件所有者串行操作，并与复位协调。回调成功表示硬件操作有序完成；实现生产 MMIO 适配器时必须满足这一约定。POP 错误无法确定是否已生效，不能依据实时 COUNT 自动恢复，也不能通过直接重新初始化实现重试；需外部核实或协调队列复位。

本阶段未提供 BSP、GIC、真实 AXI MMIO 适配器及系统生产端接线。后续完成 CSR/生产端集成和相应批次验证后，才运行完整数字核心综合。
