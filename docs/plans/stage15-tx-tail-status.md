# 第十五阶段：TX 数字尾部排空状态

所属批次为发送生命周期。本阶段交付 tx_processing_chain 的 RF 域 `tail_empty` 状态，供后续生命周期控制器使用；不把 DDS/AWG 源排空或持续 DAC valid 当作 DAC 消费完成。

实现沿用既有 58 个 RF 时钟的保守历史排空界限（FIR75 38 个输入历史拍、HB19 5 拍、两级流水线 8+6 拍、校准 1 拍）。新增状态同时检查待送路由输入、已路由 valid 和 tail_count，避免首拍输入尚未进入计数器时误报为空。零值有效样点仍计算生命周期，静音不清历史，硬复位期间不报告完成。没有修改数据路径、滤波系数、原有模式/配置切换策略和时钟。
